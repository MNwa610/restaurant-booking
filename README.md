# Система бронирования столиков в ресторане

## Назначение
Приложение для проверки возможности бронирования столика в ресторане. 
Позволяет оценить доступность столика на основе вместимости, времени и даты.

## Целевая аудитория
- Клиенты ресторанов, желающие забронировать столик
- Администраторы ресторанов

## Предметная область
Управление столиками в ресторане. Проверка условий бронирования:
- Вместимость столика
- Дата и время бронирования
- Доступность столика

## Основные сущности
- Клиент (имя, телефон, email)
- Столик (номер, вместимость, расположение)
- Бронирование (дата, время, статус)

## Основные функции
1. Проверка возможности бронирования столика
2. Валидация даты и времени
3. Проверка вместимости
4. Отмена бронирования

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей и авторизации;
- разработка REST API;
- контейнеризация приложения с использованием Docker;
- настройка CI/CD.
