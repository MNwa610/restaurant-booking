# Система бронирования столиков

Консольное приложение для учёта столиков ресторана и управления бронированиями.

## Возможности
- просмотр и поиск столиков;
- проверка вместимости;
- просмотр пользователей;
- проверка доступности столика на дату;
- создание бронирования;
- отмена бронирования;
- сохранение данных в JSON.

## Основные классы

### Table — столик
Атрибуты: `number`, `capacity`, `location`.
Методы:
- `is_suitable_for()` — проверка соответствия числу гостей;
- `validate_capacity()` — статический метод проверки вместимости;
- `__str__()` — строковое представление.

### User — пользователь
Атрибуты: `id`, `name`, `email`.
Методы:
- `from_data()` — classmethod, создание из JSON;
- `__str__()` — строковое представление.

### Booking — бронирование
Атрибуты: `id`, `table` (объект Table), `booking_date`, `user` (объект User), `is_cancelled`.
Методы:
- `cancel()` — отмена бронирования;
- `__str__()` — строковое представление с учётом состояния.

## Взаимодействие объектов

Объект `Booking` связывает объект `Table` и объект `User`:
- `booking.table` — ссылка на столик;
- `booking.user` — ссылка на пользователя.

В JSON хранятся идентификаторы связанных объектов (`table_number`, `user_id`),
при загрузке выполняется поиск объектов и восстановление связей.
