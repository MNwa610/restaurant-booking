# Система бронирования столиков

Консольное приложение для учёта столиков ресторана и управления бронированиями.

## Возможности
- просмотр и поиск столиков;
- проверка вместимости;
- проверка доступности столика на дату;
- создание бронирования;
- отмена бронирования;
- сохранение данных в JSON.

## Структура проекта
- `main.py` — точка запуска и меню;
- `tables.py` — функции работы со столиками;
- `bookings.py` — функции работы с бронированиями;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — безопасный ввод данных;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования
- Python 3.10+
- pytest
- flake8

## Установка зависимостей
pip install -r requirements.txt

## Запуск
python main.py

## Запуск тестов
pytest
